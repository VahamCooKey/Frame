# Commercial license

Frame has two licenses. Pick the one that fits how you use it.

## Free: GNU GPL version 3

You can use, copy, change and share Frame at no cost under the [GPL v3](LICENSE). That covers:

- watching videos with Frame, at home or at work
- personal, educational and non-profit projects
- free and open-source software that ships its own source code under the GPL

If you build Frame's code into your own program and give that program to anyone, the GPL requires you to release your program's source code under the GPL as well.

## Paid: commercial license

You need a commercial license from the copyright holder if you want to use Frame's source code in software that you sell or ship without releasing its source code. Typical cases:

- a paid or closed-source media player built on Frame's code
- a commercial product that embeds Frame's player, interface or playlist code
- an app store or bundled release under terms that conflict with the GPL

The commercial license covers the code written for Frame. It does not cover the third-party libraries Frame uses. mpv and FFmpeg have their own licenses, and you must arrange their terms separately. Qt is available from The Qt Company under commercial terms. See [NOTICE](NOTICE) and [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).

## Ask about a commercial license

Open an issue titled **Commercial license** in this repository. Leave out details of your deal; the issue only needs a way to reach you. The copyright holder will reply with a private contact address and the terms.
