# Using Frame

## Open a video

Press **O**, choose a video, or drop a file on the player. When folder auto-enqueue is on in Settings, opening one file also queues video files next to it in natural filename order and starts the file you chose. Opening a stream URL has no folder queue.

Drag files onto the player to choose what happens. **Play now** queues just the files you dropped and starts the first. **Add to playlist** queues just those files and leaves playback where it is. Drops never scan the containing folder.

## Playlist and viewing modes

Press **P** or select the playlist control. Cards show video previews when available. In theater mode, the playlist sits beside the video and scrolls vertically. Normal window mode and fullscreen use the horizontal shelf.

Double-click or press **F** to enter fullscreen. Press **Escape** to leave. Theater mode is available from the player controls.

## Subtitles, audio, and picture

Use the captions control to pick a subtitle track or load a subtitle file. The audio menu selects the sound track. Settings contains subtitle appearance and synchronization, sound controls, playback speed, and video adjustments. You can also change speed with `[` and `]`; press Backspace to return to normal speed.

## Continue watching

Frame remembers recent videos and playback position on this computer. Bookmarks and preferences are stored locally. Open Settings to manage appearance, playback, shortcuts, and saved history.

## Check for updates

Open **About Frame** with F12, then choose **Check for updates**. Frame checks the latest GitHub release when you ask.
