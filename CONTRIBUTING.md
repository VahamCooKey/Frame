# Contributing to Frame

Thanks for taking an interest in Frame. Open an issue before starting a large change so we can agree on the problem and scope.

## Changes

Keep the player quick to open and easy to use. Preserve existing keyboard controls and playlist behavior unless the issue calls for a change. Follow the neutral, dark interface used throughout the app. Keep platform-specific window behavior in the native platform layer.

1. Fork the repository and make a focused branch.
2. Build and run `scripts/check.ps1` on Windows or `scripts/check.sh` on Linux.
3. Describe what people can do differently after the change. Include screenshots for visible interface changes.
4. Open a pull request and link the issue it addresses.

Do not add sample media unless you have the right to redistribute it. Do not include personal media, access tokens, private URLs, logs containing private information, or build output.
