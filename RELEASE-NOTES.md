# Frame 0.8.0

Frame now has a new home at github.com/VahamCooKey/Frame. Version numbers restart at 0.8.0 here, and the update checker in this build looks at this repository.

- Screenshots show a small notice with the file name and folder. Click it to open the folder. The picture also goes to the clipboard.
- Two screenshots of the same moment get a short counter instead of failing.
- Screenshots go to Pictures\Frame unless you pick a folder in Settings.
- Fixed the window going "Not Responding" for several seconds, most often after pausing or opening a file on machines with many fonts installed.
- Interface fonts ship with Frame, so text looks the same on every machine.
- The player controls, playlist and audio view got a cleaner look.
- Plain subtitles sit clear of the controls without the picture changing size.
- Fixed a Linux startup and shutdown freeze while Frame looked for audio devices.

Coming from 1.0.0 or 1.0.1? Run the 0.8.0 setup over it and your settings stay. The update checker in those versions will not offer 0.8.0, so download it by hand this once.
